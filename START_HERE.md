# Actividad — Sesión 1

Tu equipo recibe este repositorio y un requerimiento en `TASK.md`.

La meta principal NO es resolver el bug lo más rápido posible.

La meta es construir contexto persistente suficiente para que una persona que nunca ha trabajado en el proyecto pueda abrir una nueva sesión de Claude Code y trabajar correctamente sin recibir una explicación verbal del equipo.

## Primera regla

Durante la exploración inicial no crees ni modifiques código de producción.

Investiga primero:

- qué hace el proyecto;
- cómo está organizado;
- dónde vive la lógica de negocio;
- dónde están las pruebas;
- cómo se ejecutan;
- qué patrones se repiten;
- qué archivos deberían evitarse o modificarse con cuidado;
- qué significa que una tarea esté realmente terminada.

Después decide qué información merece quedar en `CLAUDE.md`.

## Presupuesto de contexto

Tu `CLAUDE.md` debe tener un máximo sugerido de 60 líneas.

No documentes todo. Incluye únicamente información que ayude a Claude Code a tomar mejores decisiones.
